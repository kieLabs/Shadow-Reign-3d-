# Shadow Reign 3D &#8212; GamerKie Edition (Mobile Fixed)
Complete 3D WebGL (Three.js) Hack-and-Slash Action Game built for **GamerKie**.
- **4 Playable 3D Heroes:** Kuro (Shadow Blade), Akira (Crimson Ronin), Ren (Cyber Phantom), Yuki (Frost Valkyrie)
- **3 3D Arenas & Bosses:** Bamboo Shrine (Kurogane), Neon Rooftops (Lady Yurei), Obsidian Citadel (Lord Malakor)
- **Mobile & Desktop Controls:** 360&#176; Virtual Touch Joystick + Touch Action Pad & Keyboard/Mouse support.
